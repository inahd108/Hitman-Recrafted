# Recrafted Arsenal — TACZ gun pack

Original weapons for the Recrafted: Contracts mission, built for
[Timeless and Classics Zero](https://modrinth.com/mod/timeless-and-classics-zero) **1.2.0** on Forge 1.20.1.

| Weapon | Type | Notes |
|---|---|---|
| **Argento .45** | Pistol | Long-slide stainless .45, scroll engraving, ivory grips with gold medallions. 8 rounds, semi-auto, strong headshot multiplier. Uses TACZ `.45 ACP` ammo. |
| **Argento Suppressor** | Muzzle attachment | Fits the Argento and TACZ's pistol muzzle devices. Cuts the shot's audible range by 30 blocks. |

More weapons are on the way (see the main README's roadmap).

## Install

1. Install TACZ 1.2.0 for Forge 1.20.1.
2. Put `recrafted_arsenal.zip` (from `dist/` on this branch) into the `tacz` folder inside your game directory
   (`.minecraft/tacz/`, created the first time TACZ runs). Don't unzip it.
3. Restart the game, or run `/tacz reload`.

The guns appear in TACZ's creative tab and the Gun Smith Table.
To spawn one directly:

```
/give @p tacz:modern_kinetic_gun{GunId:"recrafted:argento",GunCurrentAmmoCount:8,HasBulletInBarrel:1b,GunFireMode:"SEMI"}
/give @p tacz:attachment{AttachmentId:"recrafted:argento_suppressor"}
/give @p tacz:ammo{AmmoId:"tacz:45acp"} 64
```

## How it is made

Everything is generated by `tools/armory/build.py` — no hand-edited binary files:

- `tools/armory/geomodel.py` — builds the Bedrock geometry TACZ reads, packs and paints the texture,
  and writes a Blockbench project for each model.
- `tools/armory/materials.py` — procedural stainless, bluing, ivory, gold, checkering, engraving and lettering.
- `tools/armory/guns/argento.py` — the pistol and its suppressor, part by part.
- `tools/armory/guns/argento_anim.py` — draw, holster, fire, tactical and empty reloads, inspect.

First-person hands are your own player arms: TACZ draws them at the model's `lefthand_pos` and
`righthand_pos` bones, which the animations move.

**Blockbench:** open `gunpack/blockbench/*.bbmodel` to view or hand-polish any model; it carries its
texture inside. Export it back as *Bedrock geometry* to `assets/recrafted/geo_models/...` to use your edit.

Sounds currently borrow TACZ's bundled .45 pistol sounds, so the pack needs TACZ's default pack present
(it always is unless you delete it).
